## Slide 1: 封面 / 一句话价值

**专利名称（建议）**：一种基于可加载内核模块的云宿主机 CPU 与内存硬件故障自隔离方法及系统

> **把 “整机宕机丢 100 个 VM” → “隔离一个核丢 1 个 VM”**

- 不改内核源码 · 外挂 ko
- 无下电隔离 · 绕开 hotplug 死锁
- CPU + 内存 双故障域

实现 `cpu_fault_isolate.ko`（CFI + MFI）｜ 实证 Huawei 2288H V5 + HCE2 物理机

## Slide 2: 问题 — 单器件故障 → 整机宕机

单台云宿主机承载 **上百个 VM**。任一 CPU 缓存 / TLB / 总线或内存器件出现 UCE：

```
单核 Cache 1bit 翻转 → do_machine_check() 早期 mce_panic()
   → 整机 panic + kdump + 重启 → 全部 VM 同时掉线
```

故障爆炸半径被放大到整机；事件在 panic 时刻来不及进入解码链，丧失“局部隔离、整体存活”机会。

**云厂商现实约束（决定方案形态）**：

| 约束 | 含义 |
|---|---|
| 机型异构 | Intel/AMD x86 与鲲鹏 arm64 并存 |
| 内核碎片化 | upstream 与 vendor 内核并存，关键符号未导出、无 sysfs |
| hotplug 不可靠 | vendor 内核 CPU 热插拔回调链存在硬死锁 |
| 不能改源码 | 无法为每个内核版本逐一改并重发 |

→ 需要：外挂 ko 交付、覆盖 CPU+内存、跨架构自适应的运行时自隔离方案。

## Slide 3: 现有技术与 GAP

| 现有技术 | 核心做法 | 与本方案的 GAP |
|---|---|---|
| **US 11829265 / 11385974**（VM 内存 UCE 恢复） | 内核内置 MCE handler，通知 VMM 注入模拟 MCE / 迁移 VM | 只管内存、不处理 cache/核心；逻辑内嵌内核需定制；不隔离物理核 |
| **US 12222830 / 11847036 / 11531607**（AMP 从核隔离） | NMI→自定义 panic handler→关停核→上下文切回主实例 | 面向裸机 AMP 非云宿主机；真关核；不分缓存层级；无 VM 疏散 |
| 内核既有原语（tolerant/CEC/hotplug/isolcpus） | 孤立单点能力 | isolcpus 仅启动期静态；CEC 仅 x86 无上报；hotplug vendor 死锁 |

**GAP**：无人将“外挂 ko 运行时抑制 panic + 接管 + 按缓存拓扑分级隔离核 + 无下电绕开死锁 + 白名单落点甄别 + CPU/内存双域跨架构”整合为端到端方案。

## Slide 4: 创新点 — 六大机制有机组合

1. **运行时 panic 抑制 + 接管接力**：kprobe 直写未导出 `mce_tolerant`，致命 MCE 退化为“记录+返回”回流解码链，模块接管分类隔离；双层 panic 兜底，卸载完整回滚。
2. **三档隔离 + 无下电隔离模式 ★**：full/inactive/soft 自适应；inactive 清 `cpu_active_mask` + 迁 IRQ，CPU 在线但调度/中断不可见，**绕开 hotplug 死锁**。
3. **按缓存物理拓扑分级决策**：L1/L2/TLB/总线 per-core → 隔离该核；L3/LLC socket 共享 → 仅记账上报交 daemon，避免误伤健康核。
4. **内核-用户态延迟隔离协议**：进入隔离态先通知 daemon 热迁移 VM，收 ACK 再下线；超时强制兜底，兼顾“尽快隔离”与“零损失疏散”。
5. **内核态 UCE 落点甄别白名单 ★**：页归属×消费方式×可恢复信号 二维判决；能救的救成单 VM 损失，不在白名单一律主动 kdump，**杜绝静默数据损坏**。
6. **统一双故障域 + 跨架构框架**：CPU 与内存域共用 panic 抑制/netlink/daemon；内存域含页级 CE 预隔离 + DIMM 介质记账；x86/arm64 可插拔后端。

> ★ 新颖性最强、最难规避，建议优先布局。

## Slide 5: 技术效果与业务价值

**物理机实证（同一份 `.mce` 注入）**：

| 未加载模块 | 加载模块（inactive） |
|---|---|
| `mce_panic` → kdump → 整机重启，全部 VM 掉线 | 故障核无下电隔离（迁 462 IRQ，CPU 仍在线），**整机存活**，该核对业务不可见 |

**价值**：

| 维度 | 从 | 到 |
|---|---|---|
| 爆炸半径 | 整机 100+ VM | 单 VM / 热迁零损失 |
| 交付形态 | — | 外挂 ko，零源码改动、可灰度可回滚 |
| 算力留存 | — | 隔离对齐故障域，不误伤健康核 |
| 内存侧 | 被动等 UCE | CE 前兆期预隔离 + DIMM 介质换件闭环 |

**总体**：把硬件故障从“大规模事故”降级为“单 VM 偶发重启”，杜绝静默数据损坏；一套框架统一覆盖 CPU 与内存两大宕机源、覆盖主流异构机型，显著提升公有云单机可用性与承载稳定性。
